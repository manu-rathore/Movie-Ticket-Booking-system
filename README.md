# CineBook - Movie Ticket Booking System (MERN)

## Zaroori cheezein
1. Node.js (v18+) -> https://nodejs.org
2. MongoDB (local install ya MongoDB Atlas free cloud)
3. VS Code

## Run karne ke steps (2 terminals chahiye)

### Terminal 1 - Backend
cd server
npm install
npm run seed      (sample data + admin user banata hai)
npm run dev       (server http://localhost:5000 par chalega)

### Terminal 2 - Frontend
cd client
npm install
npm run dev       (site http://localhost:5173 par khulegi)
